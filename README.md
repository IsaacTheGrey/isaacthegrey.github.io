# Federico Scaramuzza — Research & Photography

Private working copy of a personal research and photography website. GitHub Pages is not enabled.

## Editing the site

- `index.html`: biography, CV, publications, contact information, and gallery markup.
- `styles.css`: visual design and mobile layouts.
- `app.js`: gallery viewer, filters, and navigation.
- `assets/`: images, favicon, and the original CV PDF.

The gallery currently uses clearly credited sample photographs. Replace the image files, descriptions, alt text, and credits in both `index.html` and `app.js` when adding personal photographs.

## Preview locally

From this folder, run `python3 -m http.server 8000`, then open `http://localhost:8000`. Stop with Ctrl+C.

## Publication

Keep this repository private and GitHub Pages disabled until Federico explicitly requests publication. For GitHub Pages on the free plan, the repository will need to be public. When ready, publish from the `main` branch and repository root. The `.nojekyll` file lets GitHub serve the site directly without a site generator.

No installation, build step, database, or Sites integration is required.
